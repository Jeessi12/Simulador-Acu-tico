# Modelos 3D de especies

Para asociar un modelo a una ficha, coloca aquí un archivo `.glb` con el nombre común o el nombre científico de la especie.

Ejemplos válidos para **Pez Ángel Real**:

- `Pez Ángel Real.glb`
- `pez-angel-real.glb`
- `pez_angel_real.glb`
- `Holacanthus passer.glb`

La comparación ignora mayúsculas, acentos, espacios, guiones y guiones bajos. No es necesario guardar la ruta en la base de datos ni modificar JavaScript o PHP.

El visor centra y escala la geometría automáticamente. Los peces y demás especies usan vista lateral; los nombres que contienen “cangrejo”, “jaiba” o “centollo” usan vista frontal.
